# Портфолио Анны Ланкиной

Портфолио на React, TypeScript и Vite с десктопной и мобильной версиями.

Главная страница содержит Gramy, AI-сервис и My Sound. Страницы проектов:
`/gramy` и `/my-sound`; переход к следующему проекту связывает их друг с другом.
Японский концепт съёмки удалён.

Картинки проектов плавно увеличиваются при наведении, текстовые ссылки подчёркиваются
только при наведении. В карточках проектов подчёркиваются только заголовки,
описания остаются без подчёркивания. AI-сервис пока недоступен: на его превью постоянно видна
надпись «СКОРО ПОЯВИТСЯ» на затемнённом фоне, перехода на страницу сервиса нет.
На десктопе описание проекта слева скрывается при появлении блока «Следующий проект»
и возвращается при прокрутке вверх. Блок личного блога внизу страницы закрепляется
под шапкой с отступом 98 px; на мобильных устройствах он остаётся в обычной позиции.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```
